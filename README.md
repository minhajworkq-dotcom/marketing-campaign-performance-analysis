# Marketing Campaign Performance Analysis
## 📊 Project Overview
This project analyses marketing campaign performance using Microsoft Excel to understand how different campaigns, channels, customer segments and marketing activities contribute to overall business performance.
The dashboard is designed to turn campaign-level data into actionable insights that can support marketing planning, budget allocation and performance optimisation.
## 🎯 Business Objective
The main objective is to answer questions such as:
- Which campaigns generate the highest revenue?
- Which marketing channels perform best?
- Which campaigns provide better ROI?
- Which customer segments generate the most conversions?
- How much is being spent versus the revenue generated?
- Which campaigns need optimisation?
- Where should future marketing budgets be allocated?

## 📊 Dashboard Sections

### 1. Executive Dashboard
Provides a high-level overview of overall marketing performance.
Key metrics include:
- Total Spend
- Revenue
- Conversions
- ROI
- Conversion Rate
- ROAS

### 2. Campaign Performance

Compares individual campaigns based on:
- Spend
- Revenue
- Conversions
- ROI
- Conversion Rate
This helps identify the strongest and weakest campaigns.

### 3. Channel Analysis

Analyses marketing performance across different channels.
Examples include:
- Social Media
- Email Marketing
- Paid Search
- Display Advertising
- Other digital channels
The analysis helps identify which channels provide the strongest return.

### 4. Customer Segment Analysis

Examines campaign performance across different customer segments to identify:
- High-value segments
- Conversion patterns
- Revenue contribution
- Segment-level campaign performance

### 5. Time-Based Performance

Analyses campaign performance over time to identify:
- Performance trends
- High-performing periods
- Spending patterns
- Revenue trends
- Conversion trends
